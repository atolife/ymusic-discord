# Changelog

## 2.2.0

- Прямой WASAPI-захват настольной Яндекс Музыки без Virtual Cable.
- Проверка процесса по пути, PID и времени создания; поиск нового PID при восстановлении.
- Запасной режим аудиоустройства с сохранением прежнего источника.
- Публичный репозиторий, документация на русском и английском, Windows CI и автоматическая сборка релизов.

## 2.1.1

- Название трека и исполнитель в активности профиля бота.
- Отметка паузы, очистка активности после отключения трансляции и ограничение частоты обновлений.

## 2.1.0

- Карточка текущего трека с обложкой, состоянием и прогрессом.
- Сохранение ID сообщения и обновление той же карточки после перезапуска.
- Получение медиаданных из Windows, выбор плеера отдельно от браузера.

## 2.0.0

- Окно приложения, трей, настройки и индикатор входного сигнала.
- Команды `/join`, `/leave`, `/status` и роль DJ.
- Восстановление после сбоев, сон/пробуждение и необязательный автозапуск.
- Локальное защищённое хранение токена.

## 1.0.0

- Первая локальная версия: VB-CABLE → FFmpeg → отдельный голосовой бот Discord.
