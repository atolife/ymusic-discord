# Участие в проекте

Для ошибки открой Issue с версией YMusic, сборкой Windows, способом захвата и шагами воспроизведения. Не прикладывай токены и файлы личных настроек. Для предложения опиши конкретный сценарий использования.

Перед Pull Request:

```powershell
npm ci
npm run check
npm test
```

Разработку и сборку выполняй на Windows x64. Изменения захвата звука дополнительно проверяй с реальным плеером и на паузе. Не добавляй собранные EXE, записи аудио или локальные конфиги в Git. Для заметных изменений интерфейса приложи скриншот с демонстрационными данными.

Новые функции лучше сначала обсудить в Issue. Основной сценарий проекта — локальный настольный плеер и отдельный голосовой бот.
