# Участие в проекте

Для ошибки откройте Issue с версией YMusic, сборкой Windows, способом захвата и шагами воспроизведения. Не прикладывайте токены и файлы личных настроек. Для предложения опишите конкретный сценарий использования.

Перед Pull Request:

```powershell
npm ci
npm run check
npm test
```

Разработку и сборку выполняйте на Windows x64. Изменения захвата звука дополнительно проверяйте с реальным плеером и на паузе. Не добавляйте собранные EXE, записи аудио или локальные конфиги в Git. Для заметных изменений интерфейса приложите скриншот с демонстрационными данными.

Новые функции лучше сначала обсудить в Issue. Основной сценарий проекта — локальный настольный плеер и отдельный голосовой бот.
