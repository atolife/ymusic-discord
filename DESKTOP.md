# YMusic для Windows

1. Распакуйте весь архив и запустите `YMusic.exe` из полученной папки.
2. Откройте настройки токена, добавьте свой Discord-бот и пригласите его на сервер.
3. Включите трек в настольной Яндекс Музыке.
4. Выберите сервер и голосовой канал. Оставьте захват **Яндекс Музыка (WASAPI)** и нажмите **Подключиться**.

Чтобы не слышать музыку дважды, установите громкость бота у себя в Discord на 0. Остальные участники продолжат слышать его независимо.

Крестик скрывает окно в трей. Для полного выхода используйте **Завершить YMusic** или **Выйти** в трее. Перед обновлением полностью закройте старую версию.

- Подробная настройка: https://github.com/atolife/ymusic-discord/blob/main/docs/SETUP.md
- Релизы: https://github.com/atolife/ymusic-discord/releases
- Ошибки и предложения: https://github.com/atolife/ymusic-discord/issues

Windows x64 build 20348+; основной сценарий — Windows 11 и настольная Яндекс Музыка. Компьютер, плеер и YMusic должны работать во время прослушивания. Запасной режим VB-CABLE доступен в настройках.
