# YMusic для Windows

1. Распакуй весь архив и запусти `YMusic.exe` из полученной папки.
2. Открой настройки токена, добавь свой Discord-бот и пригласи его на сервер.
3. Включи трек в настольной Яндекс Музыке.
4. Выбери сервер и голосовой канал. Оставь захват **напрямую, без кабеля** и нажми **Подключиться**.

Чтобы не слышать музыку дважды, поставь громкость бота у себя в Discord на 0. Остальные участники продолжат слышать его независимо.

Крестик скрывает окно в трей. Для полного выхода используй **Завершить YMusic** или **Выйти** в трее. Перед обновлением полностью закрой старую версию.

- Подробная настройка: https://github.com/atolife/ymusic-discord/blob/main/docs/SETUP.md
- Релизы: https://github.com/atolife/ymusic-discord/releases
- Ошибки и предложения: https://github.com/atolife/ymusic-discord/issues

Windows x64 build 20348+; основной сценарий — Windows 11 и настольная Яндекс Музыка. Компьютер, плеер и YMusic должны работать во время прослушивания. Запасной режим VB-CABLE доступен в настройках.
