# Настройка YMusic

## 1. Скачай приложение

Открой [последний релиз](https://github.com/atolife/ymusic-discord/releases/latest), скачай архив для Windows x64 и распакуй его целиком. Запускай `YMusic.exe` внутри распакованной папки. Остальные файлы нужны приложению — переносить один EXE отдельно не следует.

Для готовой сборки не нужны Node.js, отдельная установка FFmpeg или Virtual Cable. Прямой режим требует Windows build 20348+; основной сценарий — Windows 11 x64. Сборки пока не подписаны цифровым сертификатом.

## 2. Создай своего Discord-бота

1. Открой [Discord Developer Portal](https://discord.com/developers/applications) → **New Application**.
2. Укажи имя приложения. На странице **Bot** получи токен через **Reset Token**.
3. В YMusic раскрой **Токен бота**, вставь токен и нажми **Сохранить настройки**. Это токен со страницы Bot; Client Secret из OAuth2 не используется.
4. Нажми **Добавить бота на сервер** и выбери свой сервер. Для этого нужны права управления сервером.
5. Вернись в YMusic и нажми **Обновить** рядом с выбором канала.

Privileged Gateway Intents включать не требуется. Поля Interactions Endpoint URL и OAuth2 Redirect URI для этого приложения не нужны.

Токен даёт управление ботом. Не отправляй его в Issues, скриншотах или сообщениях. YMusic сохраняет его локально в зашифрованном виде средствами Windows. Настройки находятся в `%APPDATA%\YMusic\settings.json`.

## 3. Разрешения

Для голосового подключения:

- **View Channel** — видеть канал;
- **Connect** — подключаться;
- **Speak** — передавать звук.

Для карточки текущего трека в текстовом чате голосового канала:

- **Send Messages**;
- **Embed Links**;
- **Attach Files**;
- **Read Message History** — для восстановления своей карточки после перезапуска.

Кнопка приглашения в приложении запрашивает эти разрешения. Для закрытого канала проверь также его собственные переопределения прав. Administrator боту не нужен. Поддерживаются обычные голосовые каналы, а не Stage Channels.

## 4. Подключи музыку

1. Открой настольную Яндекс Музыку и включи трек.
2. В YMusic выбери сервер и голосовой канал.
3. Оставь **Захват звука → Яндекс Музыка — напрямую, без кабеля**.
4. В поле приложения оставь автоматическое определение или выбери обнаруженный плеер.
5. Нажми **Подключиться**.

Захватывается дерево процессов настольной Яндекс Музыки. Приложение не переключается автоматически на общий звук компьютера, если плеер не найден.

Вывод Яндекс Музыки в микшере Windows можно оставить на обычных наушниках. Если раньше использовался VB-CABLE, верни вывод плеера с CABLE Input на наушники.

Чтобы не слышать одновременно плеер и бота с задержкой, поставь громкость бота **у себя в Discord на 0**. Остальные участники продолжат слышать его и менять громкость независимо. Громкость в самом плеере влияет на передаваемый сигнал для всех.

## Карточка и активность

Карточка появляется в текстовом чате текущего голосового канала. Она обновляется в одном сообщении: название, исполнитель, обложка, пауза и прогресс. После перезапуска приложение продолжает обновлять сохранённое сообщение. Если его удалили, при следующем обновлении создаётся новое.

Прогресс обновляется примерно раз в 10 секунд. Активность в профиле бота содержит название и исполнителя, а при паузе — отметку `⏸ Пауза`; изменения могут объединяться с задержкой до 6 секунд. После отключения от канала личное прослушивание не публикуется.

Данные поступают из медиасессии Windows. По умолчанию выбирается Яндекс Музыка, а не открытое видео в браузере. При необходимости источник можно выбрать явно.

## Команды и доступ

| Команда | Что делает |
| --- | --- |
| `/join` | Подключает бота к текущему голосовому каналу вызвавшего пользователя. |
| `/leave` | Отключает музыку, сохраняя приложение доступным для следующего `/join`. |
| `/status` | Показывает подключение, канал и источник звука. |

Команды доступны владельцу Discord-приложения, владельцу сервера, администраторам и выбранной роли DJ. Ответы видны только вызвавшему команду. Дополнительные ограничения команд могут быть заданы в настройках Discord-сервера.

## Трей и автозапуск

Крестик скрывает окно в трей. Двойной щелчок по значку возвращает его. Полностью остановить YMusic можно кнопкой **Завершить YMusic** или пунктом **Выйти** в трее.

Автозапуск с Windows и подключение музыки при запуске включаются отдельно. Сам плеер нужно запускать самостоятельно. Если переносишь папку приложения, отключи автозапуск и включи его заново после переноса, чтобы обновился путь.

## Запасной режим с VB-CABLE

Выбери **Аудиоустройство (VB-CABLE)**, направь плеер в **CABLE Input**, а в YMusic укажи **CABLE Output**. Discord и системный вывод оставь на наушниках, чтобы разговоры не попали обратно в трансляцию.

Установщик драйвера доступен на [официальном сайте VB-Audio](https://vb-audio.com/Cable/). YMusic сам драйвер не устанавливает и не удаляет. Старые `.cmd`-команды в корне репозитория оставлены для этого режима; основной интерфейс — настольное приложение.

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| Плеер не найден | Открой настольную Яндекс Музыку, обнови список источников. Оставь один экземпляр плеера. |
| Индикатор на нуле | Убедись, что музыка играет и громкость плеера не равна нулю. |
| Звук есть, но бот не входит в канал | Токен, приглашение на сервер, права канала, лимит участников и доступность Discord в сети. |
| Нет карточки | Разрешения для сообщений и вложений в чате голосового канала. Ошибка карточки не отключает звук. |
| Не появился трек | Медиасессия Windows и выбранный источник сведений о треке. |
| Двойной звук | Убавь бота только у себя в Discord; слушай локальный плеер. |
| После сбоя не вернулся | После исчерпания повторных попыток нажми **Подключиться**. Ручное отключение отменяет автовозврат. |
| Открывается старая версия | Полностью заверши её через трей перед запуском новой сборки. |
