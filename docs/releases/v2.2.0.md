## YMusic 2.2.0

Первый публичный релиз. Передавайте звук настольной Яндекс Музыки в Discord через своего отдельного бота — теперь без Virtual Cable.

### Что внутри

- Прямой захват приложения через Windows WASAPI.
- Личная громкость бота у каждого слушателя.
- Карточка текущего трека с обложкой и прогрессом.
- Название песни и пауза в профиле бота.
- `/join`, `/leave`, `/status`, роль DJ, трей и восстановление соединения.
- Запасной режим с VB-CABLE.

### Установка

Скачайте **YMusic-2.2.0-Windows-x64.zip**, распакуйте весь архив и запустите `YMusic.exe`. Нужны Windows x64 build 20348+ и настольная Яндекс Музыка. Node.js для этой сборки не требуется.

Настройка своего Discord-бота: https://github.com/atolife/ymusic-discord/blob/main/docs/SETUP.md

Чтобы не слышать музыку дважды, убавьте бота только у себя в Discord. Сборка пока не подписана цифровым сертификатом. Контрольная сумма архива находится в `SHA256SUMS.txt`.
